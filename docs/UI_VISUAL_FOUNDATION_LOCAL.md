## 视觉落地

- 表面与分隔降低生硬感，以柔和中性色承托已有阅读主题文字。
- 强调色来自冻结稿：浅色 `#8B5B4C`、深色 `#D4AC90`。面板及分组表面使用对应浅深色角色，不覆盖正文画布的主题数据。
- 共享面板标题采用系统 `.title` 的 serif 设计及 medium 字重；动作采用 `.subheadline` medium。保留 Dynamic Type，不固定标题字体像素、不安装或打包外部字体。系统实际中文回退字形仍待原生确认。
- 标题左侧保留小型圆润页边记号，装饰记号及分隔线不参与辅助功能朗读；标题保留 header trait 并允许多行。
- 共用水平内边距 20pt、顶部内边距 12pt、sheet 圆角 24pt；标题按钮触达高度至少 44pt、最小宽度 56pt。可见按钮表面仍复用已有紧凑样式，不缩减触达区。
- sheet 圆角 API 的最低系统版本为 iOS 16.4，低于项目最低 iOS 16.6。项目仍为 Swift 6.0；没有采用技能文档较新系统/语言的默认建议。
