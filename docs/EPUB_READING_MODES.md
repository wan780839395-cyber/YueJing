# EPUB 阅读方式、资源复用与版本信息

基线：63a68c3（0.2.3/build5）。本文件描述后续本地修改，不代表已发布新 IPA。

更新：下面第 1 项及第 3 项“换章重载”描述的是上一批候选，已由 [连续跨章方案](EPUB_CONTINUOUS_READING.md) 取代。正常跨章现在使用有界多章正文窗口，不采用整页换章或截图过渡；其余资源缓存与版本信息说明保留。

## 四项修复及原因

1. **连续滚动续章**：旧版仅在拖动结束检查“起手位置就在边界且外滑≥64点”，所以必须再滑一次。现在只给真实用户拖动建立资格，在本次拖动或惯性滑动到达章末/章首时自动发起相邻章节导航，一次手势只接续一次。程序化恢复、重排、工具面板、旧token不能触发。仍为单章受控渲染；跨章渲染期间短暂保留旧视口快照，不把整本书一次装入DOM。是否达到真机无感衔接需实测，不宣称已经验证帧率或零延迟。
2. **左右分页独立**：阅读设置提供“上下滚动/左右分页”，默认滚动。EPUB独立偏好键，不改变TXT设置JSON。横向采用固定页高、多栏排版；左滑/右滑及边缘点击改变x，一页等于视口宽度，不再纵向滚动一屏。滚动模式不启用横向手势。节点/UTF-16锚点保持原格式，横页、字号、尺寸变化按真实可见字符恢复，图片受页高约束，末页补足滚动范围，不额外生成空白列。
3. **重复加载**：普通SwiftUI刷新已有请求相等保护，不是根因。真实问题是控制器忽略`reloadDocument=false`，而退出时删除全部解压结果，重开重新解压和解析全书。
   - 同会话/同出版物/同章且允许复用时就地重排DOM；重绑定资源及链接到新epoch，不接受旧host。重复提交相同设置不重新导航。换章、明确重试、内容进程退出仍会重新加载。
   - 新增单本磁盘资源缓存：每次打开仍完整计算原包SHA，命中时按数据库中已验证的资源长度/SHA逐项验证并复制到独立工作目录，跳过ZIP解压及全书XHTML解析。缓存缺失、损坏或版本不符时重新构建；缓存无法写入不影响已验证的正常打开。每个阅读会话仍读取最新进度/设置、生成新session并独立清理工作目录。缓存不含会话、进度或偏好，保留单本且受256MiB资源总量限制。仍有校验和复制I/O，不宣称零读取或实测加速倍数。
4. **版本信息**：“设置→本地信息”和EPUB阅读设置末尾显示当前版本及构建号，来自`Bundle.main`的`CFBundleShortVersionString`/`CFBundleVersion`。字段缺失明确显示未知，不伪造最新版本。本次未递增构建身份，后续发布时需统一递增版本与验证入口。

## 保护边界

不改原书、ZIP/DOCTYPE/MIME净化规则、数据库迁移、TXT数据格式/业务行为、书签、EPUB parserVersion或位置单位。仅LibraryService/LibraryStore的EPUB打开路径接入复用，TXT路径未改。不开网络内容，不访问私人书籍或手机应用存储，不要求卸载、清库或重新导入。

## 验证与发布边界

本地可执行：`node scripts/check_epub_horizontal_script.cjs`（生产JS合成DOM/静态契约），浏览器合成排版辅助检查，`python -B scripts/task3_test_inventory.py --self-check`、`git diff --check`及范围/哈希检查。它们均不是Swift或WebKit原生执行。

原生待验证：
- 直接受影响的EPUB Domain打开/独立工作区/重复导入与原包修复、兼容资源重开，以及EPUB进度/会话用例；不默认重跑全部Domain或214项。
- 4项EPUB WebKit Host（加载与位置、安全、排版与两种模式、图片页），3项EPUB UI（目录/两种手势与单次续章、退出及进程重启、排版/版本与TXT隔离）。
- 当前`epub-paging-6`仍绑定旧发布范围，不能直接用它给本批缓存改动背书；后续发布须重新绑定基线、源码白名单、版本及受影响用例。
- Xcode编译、真实WebKit页面布局/手势、连续滚动衔接和真机体验尚未验证。上一版0.2.3 IPA不含本次修复。
