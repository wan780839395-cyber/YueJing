## 已定位错误及修复策略

### 1. 八个普通字号用例共享dock前置失败

运行41555973978/1的ReadingFlowUITests.swift:547，在尚未点击expand时收到collapse.isHittable=true。原始UI日志379/419/459/503/543/583/623/663对应：目录分页、正文末行、切App、主题隔离、多轮面板、关闭排版后滚动复开、进程重启、排版预设。它们均在前置阶段停止，不是八个业务功能被分别证实损坏。

源码原本同时保留紧凑/展开两组控件，使用opacity、命中与AX隐藏修饰符切换；失败后的AX快照仍暴露两组。修复为仅挂载当前活动控件树，整体隐藏时不保留工具目标。外层View持有原tray状态、同样的动作和门控；只有局部opacity/6pt过渡，不改变阅读器/模型/route身份或正文占位。保留不可见控件不可命中的原断言，不通过删除互斥断言避开错误。

这能消除本实现中保留透明控件的来源，是否解决所有XCTest/实机症状仍须原生结果。活动分支挂载有成本，本次不能无测量宣布帧率提高或“全部卡顿根因已找到”。

### 2. 最大辅助字体用例等待屏外收起按钮

同次原始日志339，对应源码656通用waitHittable超时。附件11C00232-3586-49D7-98D7-ED959575914E.txt显示collapse y691..815，窗口止于667，工具ScrollView可视y435..655。要求展开后无需滚动就能命中collapse不适配现有滚动回退。

保留大字号滚动布局，给工具ScrollView稳定标识reader.tools.scroll。展开助手先验证紧凑目标已被展开目标替代；实际目录/排版/收起操作前，只在工具自身滚动区最多3次正常慢滚动，检查目标中心在可视区域及真实isHittable，仍使用调用方原截止时间。普通目标已就绪时不滚动，不额外点正文、延时或强制显示。

最大字号用例增加真实收起、再展开及44pt检查，共享原打开排版的10秒阶段截止时间。原九个用例、业务断言、切App单次新中央点击/同PID/锚点/窗口要求、900/480/180秒预算保持，未运行到的断言不能记通过。

### 3. Host开始日志被UIKit输出打断导致独立审计失败

原Host日志2284..2285中一条started方法名被一条Unbalanced警告插入；2287完整passed、2289九项总结仍在。旧离线单行配对报counts passed identity: YueJingHostTests，不是云端Host步骤失败。

新只读审计器只还原已证实的精确UIKit警告格式、相邻两行、唯一冻结方法名的START片段，保存原始行范围与摘要，并标记derived-start而非原始完整行。通过记录不允许还原；未知、缺失、重复或跳过仍不能被写成通过。原日志与历史失败不修改，CI原计数门禁不变。真实旧证据回放和合成正负例分别记录，不算新增原生执行。

## 原生验证及必要时的诊断IPA

优先一次Task3 full/attempt1。正式IPA仍要求146项逐项真实通过、零跳过，加设备Release/依赖/资源/未签名门禁。测试失败不降低Task3门禁。

若只在UI断言步骤失败，按用户本批例外另运行一次ios-build的 `c-dock-failure-1b2117-exact6`。复用现有host_validation_run_id字段传完整验证run ID，没有增加dispatch输入或权限。门禁要求唯一固定父提交、192条完整提交/工作区/索引、仅6路径差异、手动main/attempt1、同源完整运行且只有UI步骤失败。再读取其原始步骤日志，核对九个UI身份全部结束且有断言失败，无编译错误/超时/未完成/跳过，才能继续诊断构建。使用现有GitHub临时只读令牌，不新建凭据；CDN跳转不转发Authorization，无重试。

本地只读复核还发现并修正两处验收漏洞：UI模式现在同样拒绝未知或畸形Test Case记录；每个失败case必须在自己的开始/结束区间内有可归属的XCTest断言错误，所有error行都须被归属。自动化异常、混合错误、缺少原因或case外错误均拒绝诊断构建，不能仅凭整份日志出现XCTAssert就放行。新增负例及历史日志回放验证，不改原始日志。

诊断尝试仍不运行测试，必须明确TESTS NOT RUN / full regression NOT PASSED，并保留同源完整运行的失败。原设备Release、固定官方GRDB revision/Package.swift、资源、签名、依赖闭包及原字节打包门禁全部保留。诊断构建/校验失败就无IPA，不替换旧包，不重签/重打包。Windows独立包核验后才交付。

## iPhone13 / iOS16.6.1复现记录规则

助手不能直接操作用户iPhone，也不要求用户拥有Mac。使用现有TrollStore、文件、合成TXT和系统录屏；不卸载、不清库、不改私人书籍。测试步骤会随新包来源单独交付：

1. 确认新下载包且只有C，无三布局选择；记录字号/系统文字大小、主题、低电量模式和是否发热。
2. 普通字号静止长书，观察→单次展开→单次收起，记录首次无效、误触、重叠或卡顿。
3. 最大辅助字体短书，正常工具内滚动找到收起并操作，再展开/开排版/关闭/退出，恢复系统设置。
4. 切系统设置再返回，不杀进程、不重开书、不预滑动；若工具隐藏，只点一次正文中央观察，并检查排版和远章真实更新。
5. 侧栏开/关、切栏目和辅助页；保存/复开及重启恢复只用合成书。首次异常停下，依赖步骤记阻断。

每项记录包SHA/来源、设备、步骤、预期、实际、点击次数、录屏时间码及证据来源。实际未执行写未执行；用户口述与已观看录屏分开。手机手测不能证明XCTest isHittable、同PID或精确FPS；录屏顺畅也不等于完整回归通过。当前无已证实不可修复的软件错误，只有尚未完成的原生/实机验证与访问能力边界。
