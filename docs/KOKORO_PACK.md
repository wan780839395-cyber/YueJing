# Kokoro 普通话：应用内可选下载

打开 **书斋设置 → 听书语音 → 下载离线语音包**。下载量约 147 MB，建议使用 Wi-Fi，开始前至少留出约 540 MB 空间（下载文件、已校验快照、解压暂存及余量）。不想下载可继续使用系统语音。无需浏览器、电脑、解压工具或文件选择器。

下载过程中可取消。成功后阅境会校验、解压并启用 Kokoro；常驻数据约 215 MB。可以在同一处切回系统声音，或确认后移除语音包以释放空间。失败后可点重试，从头下载；不承诺断点续传、被强退后继续下载。下载是唯一需要网络的用户操作，安装成功后合成不联网，书名和正文不会发给下载服务。

## 来源和安装边界

- 唯一入口为 sherpa-onnx 的[官方发布文件](https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/kokoro-int8-multi-lang-v1_1.tar.bz2)。匿名 HTTPS GET，不使用用户凭据；仅允许 GitHub 及指定发布资产域名跳转。不开启自动下载，不下载可执行语音引擎。
- 固定压缩包大小 147,052,523 字节、SHA-256 `259c9c8bc906d6078e4e0570421885dabb68b539c2f970fcbb890a58eeaf3e9c`。压缩包校验后，仅安装内置清单列出的 376 个普通数据文件（215,226,627 字节），包括 `model.int8.onnx`、`voices.bin`、字典、规则及许可；不安装归档里的 Python 工具。
- 在应用私有目录暂存、验证后再原子切换，不覆盖当前有效语音包。模型排除系统备份。下载中断或校验失败只清理未完成的副本。下载服务不可用时不影响系统朗读。
- 实机验收：不装包听书；点下载、取消、重试；下载完成后断网使用 Kokoro；移除后仍可系统朗读。网络可达性或归档校验不是 iOS 安装/真实出声证明。
