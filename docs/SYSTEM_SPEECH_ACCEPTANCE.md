# 系统听书：第一版真机验收

这是待执行清单，不是通过记录。使用可丢弃的合成 TXT 和可重排 EPUB，各含两章有编号的句子；不要卸载 App 或清空书库。没有云端语音、麦克风、全局播放器或锁屏媒体按钮。锁屏续播仅针对已由读者启动的朗读，不包括 App 被强退或设备重启。

| 操作 | 预期 |
|---|---|
| 从第一章中段唤出工具，点「听书」；隐藏、再唤出工具 | 两格式都从可见文字开始；工具隐藏不影响声音，阅读设置之外无新页面。 |
| 一句中暂停，改语速后继续 | 暂停不再出声；继续从该句或短片段重读，不跳到预读的下一句。播放中改速从下一段生效。 |
| 第一章临近章末时锁屏，保持熄屏至少两分钟，听到第二章编号后解锁，点「结束听书」 | 锁屏后持续出声、跨章不依赖屏幕翻页；结束后正文落到听过的句段，不回到锁屏前的旧页。两种格式分别验证。 |
| 分别在自动阅读未启动和已启动时锁屏，解锁后打开工具 | 正文恢复后「开始」应可手动点击，点击后正文实际移动；解锁本身不启动自动阅读。目录/设置能打开不能代替此项。 |
| 在 iOS 16.6.1 的同一部手机上，从普通阅读、听书工具展开、听书工具收起三种状态锁屏 | 不回桌面、不重新回到书架；听书状态还须在锁屏中听到下一段。通过模拟器或不崩但没声音均不足以验收。 |
| 用同一语速试听含「3.14」、问句和引号的同一段合成对话 | 数字不中断，闭引号不单独起读，有界长句尽量在分句处停顿。分别记录设备是否已有增强普通话音色及主观听感；低质量系统音色并不等于故障。 |
| 在书末前锁屏，等朗读自然结束，再解锁 | 不循环、不继续占用音频；位置回到最后听到的句段。这一步和上一项分别验证。 |
| 自动阅读中切换听书，再切回自动阅读 | 不同时滚动与朗读；恢复后的起点不是预读位置。 |
| 分别用未安装、已安装并选择 Kokoro、手动选系统三种配置朗读同一段编号的中文合成正文 | 未安装走系统；选择 Kokoro 后断网也应实际合成并播放，不能把系统兜底的出声当作 Kokoro 成功。测首次出声、连续跨章、调速和锁屏；未开始播放前失败应同句回退。 |
| Kokoro 合成中立即暂停、退书或改选系统语音 | 已取消的合成结果不能晚到后开播，预合成下一句也不能触发正文提前翻页。 |
| 来电打断或拔耳机 | 暂停，不自行改用扬声器继续；用户可手动恢复。 |
| 退出阅读后打开不同的书 | 旧声音停止，晚到的取文、合成和视口回调不改变新书位置。 |
| 前台听有编号的长正文（TXT、EPUB 纵排／横排），调快语速并跨页、跨章 | 当前片段开口时，若起点仍可见则不滚动；越界才露出对应正文。不要按预取位置抢先翻页。 |
| 朗读中手动翻阅，继续听两句，再点「回到朗读处」 | 翻阅不打断声音，不抢回原页；只有脱离时出现返回操作，返回最近实际听到的句段。另试在脱离时直接结束，应保留手选位置。 |
| 分别在跟随和脱离状态锁屏，跨几句再解锁 | 后台只推进语音；跟随状态在正文可用后追到最新一句，不逐句补翻；脱离状态不抢位置。 |

原生 Host 测试能检查会话状态、取文和最终 App 的后台模式声明；不能证明 iOS 在物理锁屏时实际输出声音。真机验收应记录 iOS 版本、格式、是否跨章、解锁后的文字编号和实际音频表现。阅读时长仍按前台正文统计，不把后台听书时间混入旧口径。
