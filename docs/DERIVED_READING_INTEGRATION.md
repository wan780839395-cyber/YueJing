## 默认入口与数据所有权

1. LibraryViewModel 使用 prepareReadingImport/confirmReadingImport。准入、安全域配对、协调只读复制、严格解码与原书事务沿用原链。原书提交后立即记录 committed，再用刚解码的局部 TXTDocument 构建派生包；即使旧 64MiB 内存缓存拒绝文档也能复用这次解码。产品路径不向旧完整文档缓存发布结果。
2. 重复导入先核验现有包；缺失或损坏时走一次构建。派生错误或提交后的取消只标记派生未完成，仍返回已提交的 ImportReceipt，不撤销书、版本或已保存位置。下次打开允许一次恢复，失败明确提示，不退回全书阅读。
3. openReader 每次完整读取实际源字节计算 SHA256，随后取得单代包租约、新 reading session、最新位置和设置。打开许可在 Store 中按书籍匹配；晚到旧打开不能建立或清除同书较新会话。位置仍带 book/version/raw-byte 单位，坏坐标仅忽略用于显示，不写回假的开头。
4. OpenedReader 仅包含小型书籍/会话/设置快照、DerivedBookSource 和有界布局 actor。App ViewModel 不持有完整文档或全目录。旧 prepareImport/confirmImport/openBook 和 ReadingLayoutEngine 保留，原断言与全量布局作为回归对照；默认 App 不调用旧完整阅读入口。
5. DerivedReadingLayoutEngine 仅取最多 1024 UTF16 单位前瞻、最多 7 个 slice。字素边界取包内全局位图，CoreText/NSString 只作用于局部片段；没有有限保护带猜测、字素硬切或缓冲区边缘假换行。无法前进仍抛 layoutCannotAdvance。宽度、字号、行距变化按当前可靠锚点重排。
6. 目录每页最多 32 项，上一组/下一组替换当前页，不累计全目录。跳章用原全局 raw/UTF16 范围；导航代号与 window UUID 拦住旧窗口滚动回调，目标窗口应用前不能用旧可视位置覆盖跳转目标。UIKit 应用完成后才接纳该窗口位置。

初次导入、缺包旧书迁移和损坏恢复仍采用完整 Data/正文/索引/目录构建，**不是流式导入，也不保证构建峰值内存**。已验证包的正常复开不再全书解码分章，但仍有完整源 SHA 的顺序 I/O。没有大小/mtime、抽样或 FastSeal 快捷证明。

## 任务、会话、租约与保存

- Service 只拥有一个派生构建槽。同 book/version/encoding 的消费者共享生产任务；换书、版本不符或无消费者的旧任务须取消并等待排空，再创建下一任务。任何 await 后重新匹配槽，不能误共享另一本书。单个消费者取消只撤掉自己；最后消费者取消生产者。释放/完成按 UUID 比较，旧完成不能清新槽。
- ViewModel 分别拥有打开、目录、布局和延迟保存 Task，在返回点核对生命周期、请求和位置代号。关闭、切后台和恢复撤销过期结果的 UI 安装资格；迟到句柄显式 close。后台先保存可靠位置，再清页缓存；前台复用活动句柄或重开。内存警告取消待构建任务并清页缓存，不销毁活动会话或承诺进程 RSS 降低。
- OpenedReader.close 在第一次 suspension 前关闭新写入口；并发 close 加入同一最终保存 Task，第一调用的最终锚点和设置参数生效。第二次 nil close 不能提前关会话，丢掉第一次保存。
- 最终位置、设置和 activeSession 清除在同个 GRDB 事务内；进度及设置分别检查 session 和递增 sequence。事务失败回滚数据，但写入 authority 已撤销，源租约仍释放；允许显式重试最终保存。旧会话重试和晚回调不能覆盖或清除同书较新会话。
- 只有实际用户滚动或已应用的目录导航建立新可靠位置。初开、自动排版、无进展失败和仅显示默认锚点不覆盖已保存位置。退出保存失败阻止继续操作，可重试或保留已保存位置返回。
- 每个失败打开路径关闭自己取得的源/会话；成功句柄关闭显式释放租约。坏页只失效该 generation，不清更新指针。读中自动恢复每个 ViewModel 最多一次；打开时已用过构建即消耗这次额度，手动重试是独立用户动作。原件缺失/变化或预算不足不掩盖为命中。

## 产品预算与缓存出口

ReaderStoragePolicy 当前选择：单包 **256MiB**、总派生 **512MiB**、校验元数据 **2MiB**、逻辑工作集 **8MiB**、正文单次 **8192 UTF16** 单位、目录单次 **32** 项。这些是待原生验证的工程 admission 参数，不是 RSS、用户书籍大小或“50MiB 必达”的承诺。50MiB ASCII 格式载荷约 159.4MiB，目录、摘要和两代过渡另计。

产品构建先执行识别孤儿恢复。若保守空间预留仍不足，仅产品入口按最久未阅读顺序淘汰其他书的未租用包，跳过活动构建和任何租用 generation；正在替换的同书旧包保留至新包发布。只条件删除派生指针及确切 UUID.pack 普通文件，不递归，不动原 TXT、书架、进度或未知命名项。回收后只重新 admission 一次，仍不足即失败。旧显式存储 API 默认仍仅拒绝预算不足，保留原测试合同。

页缓存、元数据和返回片段有独立逻辑计账，不包括全部 Swift 分配器、CoreText、UI、系统缓存或初次构建峰值。内存警告只清可释放页；关闭后数据源保留累计读取计数，逻辑保留字节报 0。真实磁盘满和 I/O 失败仍可能出现，派生失败不删原件或可靠进度。
