# EPUB 阅读翻屏与章节接续

## 反馈与原因

基线为0.2.2/build4，提交99ed646。用户真机确认导入成功、内容显示正常，进一步确认目录跳转和章内上下滚动正常；实际缺陷是到章末后无法继续下一章。不是目录解析失败。

原实现每次只服务一个spine章节，滚动结束仅采样位置，没有相邻章节接续；左右滑动与边缘点击翻屏也未实现。WKWebView未显式禁用pinch，原viewport只规定初始比例，仍可双指缩放。

## 本批行为

- 继续保留原有纵向滚动与目录/锚点跳转。
- 章末再次向上外滑至少64点进入下一章开头；章首再次向下外滑返回上一章末尾。只有从边界开始的明确纵向手势有效，不让从章中甩到末尾的惯性直接跨章；不足一屏的图片章也可接续。
- 左滑下一屏、右滑上一屏；点击左右20%边缘区域同样翻屏，排除顶部/底部56点及链接/文本选择。每屏保留最多64点上下文；到边界后接续相邻章节。不改为横向分页排版，也不增加新的全局翻页模式设置。
- 首章/末章不循环跳转。跨章同步关闭旧token的交互资格，快速重复手势、旧epoch、关闭/挂起及面板期间输入不能发起新跳转。
- 上一章末尾定位先等待图片布局稳定，再采样真实可见节点。进度仍采用原文本节点/UTF-16单位；目录锚点与明确保存位置优先，不存临时屏幕页码。
- viewport限制缩放比例，且在创建、布局和加载完成时禁用原生pinch识别器；保留阅读设置中的字号调节与系统无障碍能力。VoiceOver保留原手势，并提供上一屏/下一屏命名操作。

## 保护边界

不改导入/解包/MIME纠正/净化、正文资源字节、图片样式、spine目录、数据库、parserVersion、位置单位、TXT、书签、工具链或依赖。无需重新导入、卸载或清理用户数据。私有原书未重新读取或上传；自动回归只用合成EPUB。没有访问手机应用数据库，不声称独立检查过手机实际导入文件；当前导入显示及目录成功来自用户确认。

## 验证范围

本地执行生产定位JavaScript的8个合成DOM场景：章末真实采样、等待图片、旧锚点优先、目录fragment优先、默认章首、短章、过期回调拒绝和节点完整性拒绝；这是Node执行，不是WebKit。另检查测试身份、原断言、源范围/哈希及git diff格式。

既有Host测试扩展几何边界、跨章/重复/旧token拒绝、章末落点、关闭重开与禁用缩放；既有EPUB UI测试扩展实际横滑、边缘点击、边界纵滑和pinch后的显示/翻屏。未增加或删除测试身份。

本批获准发布0.2.3/build5，采用`epub-paging-6`：4个EPUB Host（正文加载/恢复、安全、排版与跨章、兼容图片页）+2个EPUB UI（目录与翻页、退出/进程重启进度）。逐项运行既有身份，不运行整个测试套件；Host总预算480秒、UI总预算1200秒，单项180秒，不自动重跑。需要真实UIKit/WebKit与源码同源验证，不可用上批33项替代。未改动Domain导入等以run41974484958历史证据作隔离参考，不默认重复214全量。

既有Task3工作流为新范围执行独立任务，固定工具链/依赖不变；6项原始事件、命令、源码、run/attempt、模拟器和依赖收据全部匹配后，才构建设备Release并校验链接、资源、unsigned arm64/iOS16.6及IPA逐文件字节。发布范围以99ed646为基线，限定14个文件；项目配置仅递增版本号。失败保留原始证据，仅按用户授权修复具体范围内问题后普通提交、推送及重新验证，不降低断言或放宽安全门。

Windows本地检查不是Swift编译或iOS执行。实际测试、构建和IPA结果另存本批发布证据，真机交互修复仍需安装验收；旧0.2.2不包含本批改动。覆盖安装保留书籍和进度，不要求卸载、清数据或重新导入。
