## 目录布局与行为

### 连续章节列表

- 保留原 `List` 与按真实章节 ID 建立身份的有界列表，不全量展开目录。
- 新章序为 `page.start + item.offset + 1`，仅作装饰显示；不替代章节 ID、锚点或完整章节标题，不裁剪或解析原章节名。
- 辅助字号下隐藏装饰章序，为完整标题留出空间；常规字号保留章序栏。
- 当前章沿用原 `currentIndex` 判断，增加圆润页边线，并保留勾选图形。装饰均不重复朗读，原“当前章节”辅助功能值不变。
- 原选章动作中的 `active` 与捕获的 `ownerRevision` 校验、`.id(item.element.id)`、`reader.chapter.*` 标识和焦点绑定保留。

### 固定面板底部区

- 底部区是 `List` 之外、同一 `ScrollViewReader` 内的纵向布局兄弟节点，不是覆盖层，也不在正文视口上增加 inset。
- 仅当已有非空目录页时显示；无页和空目录不显示虚假的范围或翻组控件。
- 显示原 `page.rangeLabel`，没有额外范围缓存、预测页号或提前更新。载入/失败保留旧页与旧范围的逻辑仍由原状态机负责。
- “回到当前章节”“上一组”“下一组”均由父页面传入原调用；控件不创建任务或持有模型。
- 上一组禁用条件仍为 `page.start == 0 || model.state.loading`；下一组仍为 `page.start + page.chapters.count >= page.total || model.state.loading`。
- 分页目标仍按 `ReadingDirectory.pageSize`（32）计算，不改原边界或加载协议。
- 父页面对新底部区应用 `.disabled(!active)`，且每个回调保留原 `if active`。回到当前章节不额外按 loading 禁用，保持原有请求语义。
- 常规高度下定位动作在翻组行上方；横向空间不足时范围另起一行。紧凑高度下定位动作使用图标，但保留完整辅助功能名称，并有多行备选布局。
- 所有底部按钮声明至少 44pt 的宽高触达下限。底部区遵循面板正常安全区布局，不新增忽略安全区或绝对定位。

### 目录生命周期

- 目录属性和共享标题区与基线一致。
- reveal 任务仍附着于 `List`，任务体、请求匹配校验、`scrollTo` 和 VoiceOver 焦点逻辑不变。
- owner/presentation 任务、退出清理与 Escape 关闭仍附着于原页面层级，相关代码尾段与基线一致。
- 错误、重试、无目录与载入提示的原分支保持；`retry` 仍沿用原策略，不改成新的请求重试协议。

## 排版布局与行为

- 保持“示例预览 → 文字 → 阅读背景 → 快捷排版/恢复 → 辅助入口”的原顺序。
- “字、色、式”标记仅作装饰；标题保留 header trait，说明文字可换行。用细分隔替代三个厚重外层卡片，不叠加新的模型或状态。
- 两个调节控件的绑定、范围、提交回调不变：字号 14–36，行距 0–20。控件实现文件未修改。
- 主题网格、预设网格及恢复按钮的动作、标签、选中状态和禁用条件保留。预设仍为紧凑 17/5、标准 20/7、宽松 24/10。
- 属性、初始化、主界面头部、生命周期、确认对话框、辅助 sheet 和 Escape 行为保持原代码。
- `apply`、`commitDraft`、`finish`、主题按钮、诊断/许可动作不变：滑动预览、松手提交；加减/预设立即应用；恢复保留当前背景和阅读位置；完成只关闭面板。
- 诊断和开源许可仍保留在原低频区域，没有迁移或删除入口。

### 预览

- 固定非私有示例文字、PingFang 字体绑定、所选字号、行距、背景/前景色均沿用原来源，不读取小说正文。
- 移除 `.lineLimit(3)`，为示例添加按宽度换行、按内容增高的布局路径；没有最大高度上限或裁剪。
- 元信息提供横向与纵向候选，说明/数值随系统语义字体缩放；示例本身继续反映用户所选阅读字号，而不是改为另一套系统字号。
- 新增轻描边与页边色线；保留原辅助功能汇总、隐藏重复示例朗读和 `reader.typography.preview` 标识。
- 实际极值字号、行距和窄屏渲染是否完全无截断，仍属于原生待验项，不能由文本规则代替确认。
