## 本地落地内容

### 书架与真实数据

- 保留 `List` 与 `ForEach(model.books)`，继续使用书籍自身的稳定 ID；不增加排序、过滤或全量书目转换。
- 标题、书目数量及最近阅读日期来自现有数据。保留原 `Date(timeIntervalSince1970: date)` 和系统日期显示；没有记录时显示“新加入 · 尚未阅读”。
- 不新增虚构的“在读”状态、作者、进度、字数、EPUB 书目或演示书籍。
- 实际书目当前仍来自 TXT 导入链，因此行内仅标 TXT。格式扩展并没有接入。
- 封面只绘制标题首个 `Character` 与轻量形状，不访问文件、不解码图像、不下载或缓存图片。未来图片接入需另行明确范围。
- 书架标题和书名使用可缩放的系统语义字体；仅作为装饰的封面字形固定在占位区域内，并从辅助功能树隐藏。

### 系统浅深色与层次

- 书架和规划说明页各自从 `@Environment(\.colorScheme)` 建立管理页外观，不读取 `ReaderPreferences` 或 `ReaderTheme`，不强制全局 `preferredColorScheme`。
- 保留冻结稿的朱赭强调色、柔和中性色、书卷字阶及圆润边界。未改动上一批阅读面板样式。
- 书名不设行数上限；阅读日期通过 `ViewThatFits` 在横向排布与多行排布间选择。
- 书目、工具入口与信息入口至少保留 44pt 触达高度；模块入口至少 60pt，并允许内容增高。

### 扩展入口及门控

- 漫画聚合、AI 故事放在书架下方“更多故事”区域，显示“规划中 · 未接入”。
- EPUB 与封面使用次级说明链接，显示“预留”；说明页再次标明“布局预留 · 未接入”。
- 所有新入口只通过已有 `NavigationStack` 中的 `NavigationLink` 打开静态说明页，没有新的导航所有者或额外 sheet。
- 新入口仅在以下条件同时满足时可操作：书架服务存在、原选择器已确认关闭、没有导入、没有编码确认、没有待显示的提示弹窗、没有阅读呈现。
- 该门控仅用于新增入口。原诊断和 TXT 导入按钮仍分别使用原 `canPresentLibraryFeedback`、`canBeginFileSelection`，没有修改它们的含义。
- 不扩大文件准入、不实现 EPUB 解析、不接漫画内容源、不调用模型、不引入账户、额度、凭据或新持久化。

## 保留的现有行为

- `ContentView` 的初始化和服务工厂不变。
- 从 `library.screen` 标识开始到文件末尾的全部原代码保持一致：阅读全屏呈现、route ID、显式退出、首次打开、内存警告、阅读退出后刷新、文件选择交接、编码确认、提示弹窗以及 `readerPresentation` 绑定。
- 提示、导入进度、请求停止、空架和重新打开书架的分支，除行背景外保持原表达式、文字、动作与门控。
- 书目打开仍是原 `readerRoutes.open(bookID: book.id, service: service)`，没有增加延时或等待动画完成。
- 原阅读路由在 `open` 内同步发布 presentation；本批不改动路由实现，仅通过现有 presentation 判断新增入口是否可用。
- 本批不新增自定义动画、异步布局任务或等待逻辑。规划页使用系统导航过渡；阅读动效的独立批次尚未开展。
